# tests/sample-words.json 是什么

不是完整语料，只是一份**回归样本**：约 150 个手选高频词（关系层、词级配方、修饰字、天气、人体、校园、生活物件各覆盖几个），加 20 个随机词防止"只优化了样本"。

用途只有一个：让 CI 能在没有完整词表的情况下也跑验收——硬伤、同构图重复率、可画率三条线都会在这 170 个词上暴露。

```bash
node scripts/validate.js --batch tests/sample-words.json --max-dupe 12 --fail-dupe --min-drawn 60
```

阈值为什么是 12 而不是完整语料的 150：样本只有 170 词，同一个"单人"骨架本来就会命中十几次（人、老人、男人、女人…），这是正常的复用，不是退化。

加词的判据：新写的关系骨架、新的词级配方、新的图元，各挑 1–2 个代表进样本；**别把整个游戏词库拷进来**。
