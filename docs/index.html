三种画法同一份图元 · 换后处理

彩色承载语义，适合低识字量；墨线只描边，省墨、手账气质；水墨靠多点叠印伪造柔边，适合古诗山水。点卡片右下角切换画法——同一份图元，只换后处理；同一批只能一种画风。

关系层关系决定构图，不是把两个图标并排

并排只是十种关系里的一种。递进画台阶与方向，动作画作用弧，因果画上下与下坠箭头——同一批词因此像一家人。

词级配方按字取图一定错的词

"太阳"两个字都没图元，"学生"会被画成"学校+幼苗"，"马路"的路面上会站一头牛。这类词绕开字，直接写"画哪两张图 + 什么关系"。

动效语义词本身就是"过程"

滴水、冒烟、融化、摇晃、飞舞、坠落、滚动、燃放、沸腾——这些词定格怎么画都差一口气，它们说的是"正在发生"。画面自带 SMIL 动画，下面这些卡片是真的在动（静态导出自动落在最有代表性的首帧）。

拟态符号没有主体可画，就画"感觉"的记号

香、吵、疼、累、急、怒、怕、晕——这些词缺的不是图元，是"感觉怎么画"的约定。漫画早给了现成语汇：汗滴=累、三道蒸汽弧=怒、上飘热浪=热、两缕线=气味、外扩弧=声、红斜杠=静。这批记号收进 SYM（15 枚），只挂四角槽位，一卡最多两枚；先把"能画的物"画完，符号是最后一招。

拆字会意部件本身就是图

会意字的图不用"找物件"：日+月=明、人倚木=休、手搭目=看、宀下火=灾、三木=森。这一层同时讲对了字形与字义，对识字场景最划算。18 个字的部件表 + 三套版式（左右 / 上下 / 三件），但只有"词义 = 字形义"的词才许启用。

借场景抽象词借一个念得出词义的生活场景

抽象词没有实体，但多数在生活里有场景。两件最多三件图元搭一个：嫩芽+初升的太阳=希望，人+一座比自己高的山=困难，靶心+射中红心的箭=目标，人挑担子=责任。判据只有一条：遮住词牌念一遍，念的是不是这个词——帮助（大人指小孩→"指"）与 机会（开着的门+星芒→"告示牌"）都因念不对而撤掉。

补件与借动作先参数、再补件、最后借动作

会意字卡住多半是缺部件。"女/子"不必新画——A.person 早带 dress/hair:'bun'/child；真缺的只有豕（A.pig），补上后 家、安 都立住。器物补了冠/帽/刀/面包。抽象词像"力"没有可画之物，就借动作：人举石念得出"力气"，推石上坡念得出"努力"——但"制度""逻辑"借什么都念不出，直接字牌。

状态双帧 / 程度刻度两态并排，记号叠数表轻重

"开关""昼夜"这种词说的是两个状态之间的差：左右两帧同一件东西，中间一道虚线加箭头，念出来就是"从关到开"。程度词则用同一枚记号叠 1/2/3 次——一层热浪是温、三层是滚烫；一层冰晶是凉、三层是冰凉。不新增图元，只借参数与重复。

图元是零件 + 装配换参数，不是复制函数

山有尖峰、缓坡、高原、双峰；水有波纹、湖面、急流；树分阔叶与针叶。判据是：换个数还认得出是同一个东西，就加参数。

开始用零依赖 · Node ≥ 18

# 单张
node scripts/render.js 山水 out.svg
node scripts/render.js 山水 out.svg --style doodle --size 300 --label

# SVG → PNG
python3 -c "import cairosvg;cairosvg.svg2png(url='out.svg', write_to='out.png', output_width=600)"

# 批量验收（硬伤非 0 退出）
node scripts/validate.js --batch words.json --max-dupe 8
# 词级配方：绕开"字"这一层
WORDS['学生'] = { hi:'person', si:'book', rel:'ACT' }
WORDS['医生'] = { hi:'person', mark:[['cross']] }

# 图元变体：零件 + 参数
A.mountain({ shape:'round', top:26, snow:'heavy' })
A.water({ form:'lake' })
A.tree({ pine:true })

# 拟态符号：没有主体的感觉词
WORDS['害怕'] = { hi:'person', mark:[['sym','sweat'],['sym','tremble']] }
WORDS['寂静'] = { hi:'moon', mark:[['sym','mute']] }

# 动效语义：网页里会动，静态导出是首帧
bodyOf('融化')                  // 带 SMIL
bodyOf('融化', { anim:false })   // 去掉动画
