# 拟态符号：给"没有主体"的词画一句话

有些词**找不到可画的东西**：香、吵、疼、累、急、怒、怕、晕。它们不是缺图元，是缺"感觉怎么画"的约定。漫画早就给了现成语汇——汗滴表示累、三道蒸汽弧表示怒、上飘热浪表示热、两缕线表示气味、外扩弧表示声音、红斜杠表示静音。这一层把这些记号收进一张 `SYM` 表。

## 15 枚符号

| 名 | 画的是什么 | 配哪些词 |
|---|---|---|
| `sweat` | 汗滴（三瓣水滴 + 两粒汗珠） | 累、怕、紧张、繁忙、困倦 |
| `anger` | 三道红色蒸汽弧 | 怒、生气、呐喊、怒吼 |
| `tremble` | 两侧短折线（发抖记号） | 紧张、惊慌、忧伤 |
| `heat` | 两道上飘热浪 | 热、温暖 |
| `frost` | 冰晶 + 短刺 | 冷、寒冷 |
| `scent` | 两缕上行气味线 + 两点 | 香、香味 |
| `sound` | 三道外扩弧 | 吵、呐喊 |
| `mute` | 声波 + 红斜线 | 静、寂静、幽静 |
| `dizzy` | 头外侧绕圈 + 小星 | 晕 |
| `pain` | 红色菱形锐刺 + 放射短线 | 疼 |
| `hurry` | 速度线 + 红感叹号 | 急、紧急、赶忙 |
| `bang` | 竖感叹号 | 吃惊、惊叹、惊慌 |
| `ask` | 弧 + 点画的问号 | 疑问、惊异 |
| `spark` | 两枚金色星芒 | 高兴、快乐、喜悦 |
| `tear` | 泪滴 + 垂弧 | 难过、伤心、悲哀 |

符号只表达**语气**，不表达主体。所以符号永远和一张主体图配对出现（`花 + 气味线` = 香，`人 + 泪滴` = 悲），单独一枚符号不成词卡。

## 怎么挂

符号走 `mark`，和 `cross`、`zzz`、`sparkle`、`arrow` 同一套机制：

```js
WORDS['害怕'] = { hi: 'person', mark: [['sym', 'sweat'], ['sym', 'tremble'], ['sym', 'dark']] };
WORDS['幽静'] = { hi: 'moon', si: 'house', rel: 'SIDE', mark: [['sym', 'mute']] };
```

`['sym', name]` 与 `['sweat']` 这类裸装饰的区别：**裸装饰按字面名字查 `decorOf`，`sym` 明确走符号表**，避免和已有装饰撞名（早前 `累` 写成 `['sym','zzz']`，`SYM` 里没有 `zzz`，结果画出一张空卡——这是最容易踩的坑）。

## 槽位

```js
const SYM_SLOT = [[0, 0], [-56, 2], [2, 34], [-58, 34]];  // 右上 → 左上 → 右下 → 左下
```

`decorOf` 按 `mark` 里 `sym` 出现的**顺序**取槽位。所以一卡两枚符号时是"右上 + 左上"，三枚才用到下排——**顺序即位置**，不要指望它自动避让。

四条硬约束：

1. **一卡最多两枚符号**。三枚以上像爆炸现场。`呐喊`（声波 + 怒气）、`忧伤`（泪滴 + 颤抖）是上限样本。
2. **只落四角，不压脸**。76px 下面部只有十来个像素，符号压上去主体就没了。
3. **同义词可以同图，近义词不行**。`赶忙 / 赶紧 / 连忙` 是同一件事，共用"跑者 + 速度线 + 感叹号"是诚实；`宝石` 和 `石子` 一个词一颗，必须看起来不同。
4. **符号是最后一招**。先看有没有可画主体（有就走图元/配方），主体会画歪（`罕见` 画成眼睛）或压根没有，才用符号；符号也兜不住就进 `PLATES`。

## 配方词不叠加单字装饰

`bodyOf` 里一句关键逻辑：

```js
const dec = p.spec ? [] : mod.decor;   // 命中词级配方时，单字装饰一律清零
```

原因是 `热 / 冷` 这类单字在 `MOD` 里带 `swatch`（右上色片）。配方词沿用单字装饰时，色片会飞到右上角，正好盖住 `heat` / `frost` 符号，图上就多出一颗红/蓝小圆点。规则是：**配方的画面由配方自己负责，字层装饰不再参与**。

## 进阶一：程度刻度（同一枚符号叠数）

轻重不靠换符号，靠**重复**。`mark` 里同一枚写几次就是几级：

```js
开水: { hi: 'cup',  mark: [['sym', 'heat'], ['sym', 'heat']] },                     // 2 级热
滚烫: { hi: 'bowl', mark: [['sym', 'heat'], ['sym', 'heat'], ['sym', 'heat']] },     // 3 级热
```

规则：**1 = 轻、2 = 中、3 = 重，最多 3**（`SYM_SLOT` 只有四个槽，第四枚会挤满最后一只角，主体就没了）。换符号会读成"另一个词"，叠同一枚才读成"更"。

**但只有紧凑记号能叠**。热浪、冰晶、气味线是竖向短线，叠 2/3 枚只是变密；声波、星芒这类向外放射的记号一叠就互相压住，读成一团乱线——`洪亮` 试过三重声波（9 条弧挤在右下角），最后改成"单枚声波 + 感叹号"表力度。

## 进阶二：状态双帧（差值词）

`开关`、`昼夜`、`满/空`、`整/碎` 说的是**两态之差**，单帧只讲一半。`dualPanel(a, b)` 把两帧各缩到 46% 并排，中间一道虚线 + 箭头：

```js
WORDS['昼夜'] = () => dualPanel(A.sun(), A.moon());
WORDS['开关'] = () => dualPanel(A.bulb({ on: false }), A.bulb());
```

配套的器物状态参数：`A.bulb({on:false})` 灭、`A.door({open:true})` 开、`A.bowl({full:true})` 满、`A.cup({broken:true})` 碎。

判据：**缩到 46% 还认得出两帧分别是什么**。认不出就不是双帧问题，是图元本身不够辨识，先去修图元。

## 加一枚新符号

1. 先确认它不是"物"——是物的图元该进 `A`，不是符号。
2. 在 `SYM` 里加一个纯函数，返回 `<g>` 字符串，坐标系是 100×100 的卡面，符号自身中心落在四角槽位附近（约 ±8 半径内可读）。
3. 只用 `el / cir / pth / ln / arc` 这些基础件，**别用滤镜**（cairosvg 不支持）。
4. 在某个情绪/状态词上试一张，缩到 76px 看还认不认得出。
5. 跑 `node scripts/demo.js symbols` 与 `node scripts/validate.js --batch`，再看 `stats()` 是否掉档。

符号层的边界很硬：它只补"感觉/状态"，不补"人事物"。`诚实`、`制度`、`逻辑` 这类抽象名词照样字牌，别指望加符号把覆盖率拉起来。
