# 借场景：抽象词没有实物，就借一个"念得出词义"的场景

`希望`、`困难`、`目标`、`危险` 这类词没有可画的实体，但**每个词在生活里都对应一个具体场景**。借场景比借动作（见 CONTRIBUTING 第 12 条）更辽阔：动作只有一个，场景可以搭。

## 8 个已启用的场景

| 词 | 场景 | 为什么念得出 |
|---|---|---|
| 希望 | 嫩芽 + 初升的太阳 + 上升箭头 | 芽往光长 = 有希望 |
| 未来 | 一条通向远方的路 + 初升的太阳 | 路在前、日未高 = 还没到的日子 |
| 危险 | 人 + 头顶雷云闪电 + 感叹号 | 天打雷人还站着 = 危险 |
| 困难 | 人 + 一座比自己高得多的山 | 要爬一座大山 = 困难 |
| 漂亮 | 花 + 星芒 | 花发光 = 好看 |
| 目标 | 靶心 + 一支射中红心的箭 | 箭入靶心 = 目标 |
| 责任 | 人肩上横着扁担、担着箱子 | 挑担子 = 责任 |
| 感动 | 心 + 星芒 + 一滴泪 | 心暖到掉泪 = 感动 |

## 怎么搭

`SCENE` 是一张整幅函数表，和 `MOTION` 同构，直接拼现有图元：

```js
const SCENE = {
  目标: () => g(
    at(30, 8, .68, A.target()),
    ln(4, 86, 62, 52, 2.4, C.ink2),          // 箭杆
    pol('66,50 56,48 58,60', C.ink2),        // 箭头
    ln(2, 86, 98, 86, 2.4, C.ink2)),         // 地平线
};
```

四条搭法：

1. **两件就够**。场景不是插画，超过三件要素就变成"猜谜拼图"：`希望`=芽+太阳，`困难`=人+山。
2. **一物定方向**。景里必须有一件东西"指向词义"：太阳的方位、箭的落点、担子的重量。少这件，图就只是两个图标并排。
3. **地平线统一**。人和物都踩同一条 y=86 的线，否则读成悬空。
4. **符号收尾，不铺细节**。`危险` 的感叹号、`感动` 的星芒与泪滴负责"语气"，别再加第三样。

## 判据：遮住词牌，念一遍

这是唯一标准，且必须由人来做：

- `目标` → "射箭打靶" ✓
- `困难` → "人要爬大山" ✓
- `责任` → "挑担子" ✓
- `帮助` → 试搭过"大人指小孩"，念出来是"指"，不是"帮" → **撤掉**
- `机会` → 试搭过"开着的门 + 星芒"，念出来是"门开了"或"告示牌"，不是"机会" → **撤掉**
- `制度`、`逻辑`、`礼貌`、`孤独`、`寂寞` → 借什么都没用，**留字牌**

## 加一个场景词

1. 先问：这个词有没有一个"人人都会做"的具体场景？没有就别勉强。
2. 挑两件最多三件图元（`A` 里的键名），确定哪一件"指向词义"。
3. 新建 `data/scenes/<词>.js`，统一地平线。
4. 渲染后缩到 76px，遮住词牌念一遍；念出来不是这个词就退出。
5. 跑 `node scripts/demo.js scene` 与 `node scripts/validate.js --batch`。
